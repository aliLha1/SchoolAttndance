# نظام إدارة الغياب المدرسي — Android

تطبيق أندرويد بواجهة عربية RTL لإدارة الطلاب والحضور والغياب والتقارير والنسخ الاحتياطي المحلي.

## المزايا
- لوحة رئيسية بإحصائيات اليوم.
- إدارة الطلاب حسب الصف والشعبة، مع بيانات ولي الأمر والهاتف.
- تسجيل حاضر / غائب / متأخر / بعذر لكل يوم.
- تقارير يومية ونسبة الحضور وتصدير CSV.
- نسخ احتياطي واستعادة JSON باستخدام نافذة اختيار الملفات في Android.
- أدوار دخول أولية: مدير ومعلم، مع إمكانية تغيير رموز الدخول من الإعدادات.
- قاعدة بيانات SQLite محلية ولا يتطلب التطبيق صلاحيات إنترنت.

## الدخول الافتراضي
- المدير: `1234`
- المعلم: `2222`

**غيّر رموز الدخول فوراً عند أول استخدام.** هذه صلاحيات محلية بسيطة مناسبة كنموذج أولي وليست نظام مصادقة مؤسسياً. البيانات تبقى على الجهاز ولا توجد مزامنة سحابية في هذه النسخة.

## فتح المشروع وبناء APK
1. نزّل الملف المضغوط وفكّه.
2. افتح مجلد `SchoolAttendance` من Android Studio (Giraffe أو أحدث، والأفضل إصدار حديث يدعم Android Gradle Plugin 8.7.3).
3. اسمح بمزامنة Gradle وتنزيل الاعتماديات، وثبّت Android SDK Platform 35 إذا طُلب ذلك.
4. من القائمة اختر **Build → Build APK(s)**.
5. ملف APK التجريبي يظهر عادةً في `app/build/outputs/apk/debug/app-debug.apk`.

يمكن أيضاً البناء من الطرفية بعد تثبيت Android SDK وGradle:
```bash
gradle assembleDebug
```

## بنية المشروع
- `app/src/main/java/com/school/attendance/MainActivity.kt`: الواجهة والمنطق وقاعدة SQLite.
- `app/src/main/AndroidManifest.xml`: تعريف التطبيق.
- `app/build.gradle.kts`: إعدادات البناء والاعتماديات.

## حدود النسخة الحالية
- لا يوجد تسجيل دخول عبر الإنترنت أو مزامنة بين أجهزة.
- صلاحيات المعلم حالياً تمنع تعديل الإعدادات وإضافة/حذف الطلاب من الواجهة، لكنها ليست تشفيراً للبيانات.
- استعادة النسخة الاحتياطية تستبدل الطلاب وسجلات الحضور الموجودة.
- قبل الاستخدام الفعلي في مدرسة، يوصى بمراجعة أمنية، وتشفير النسخ الاحتياطية، وإضافة تعديل بيانات الطالب وسجل تدقيق وصلاحيات أكثر تفصيلاً.
